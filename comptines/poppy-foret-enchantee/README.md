# Poppy dans la forêt enchantée

Comptine chantée, 30 s, format vertical 9:16 (TikTok / YouTube Shorts), 1080 x 1920.

▶️ **Vidéo finale : [`poppy-foret-enchantee.mp4`](poppy-foret-enchantee.mp4)**

## Paroles

> Poppy, petit chat tout blanc,
> Se promène en chantonnant.
> Les champignons sont tout brillants,
> Les papillons dansent au vent.
> La la la, forêt enchantée,
> Viens avec Poppy te promener !

## Poppy

Chat blanc tigré gris, yeux verts, collier rose avec perles, clochette dorée et petit cœur.

## Comment elle a été fabriquée (100 % gratuit)

| Étape | Fichier | Outil |
|---|---|---|
| Voix de femme qui chante | `chanson.py` | Voix française libre Piper « siwis » + vocodeur WORLD (chaque syllabe placée sur sa note) |
| Musique | `chanson.py` | Boîte à musique, nappe, basse et carillons synthétisés (musique originale) |
| Images 3D | `scene.html`, `scene.js` | Three.js (forêt, champignons lumineux, lucioles, papillons, rayons de soleil) |
| Montage + sous-titres karaoké | `rendu.cjs` | Navigateur sans écran + ffmpeg |
