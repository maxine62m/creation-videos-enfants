# 🎬 Studio Comptines

Studio de vidéos animées pour enfants, utilisable **uniquement depuis un iPad**, **100 % gratuit**.

## Ouvrir l'app sur l'iPad (une seule fois, 2 minutes)

1. Sur github.com, ouvre ce dépôt → **Settings** → **Pages**.
2. *Source* : **Deploy from a branch** → branche `main` (ou `claude/kids-animation-studio-94bwps` pour tester) → dossier `/ (root)` → **Save**.
3. Attends 1 à 2 minutes : l'adresse s'affiche en haut (`https://<ton-pseudo>.github.io/creation-videos-enfants/`).
4. Ouvre-la dans **Safari** → bouton Partager → **Sur l'écran d'accueil**. L'app a maintenant son icône.

> GitHub Pages est gratuit pour un dépôt **public**. Pour un dépôt privé, il faut un abonnement payant : ne l'active pas sans le vouloir.

## Faire une vidéo

1. **Personnage** : nom, espèce, couleurs, accessoire. « Exporter la fiche » pour le garder à l'identique.
2. **Comptine** : choisis un thème → « Générer » → modifie le texte si tu veux. Une ligne vide = une nouvelle scène.
3. **Voix & musique** : enregistre ta voix en lisant la comptine (facultatif), choisis une mélodie.
4. Choisis le format (**Shorts/TikTok 9:16** ou **YouTube 16:9**) → **Créer la vidéo**. Laisse l'écran allumé.
5. **Partager** → YouTube, TikTok, Photos ou Fichiers.
